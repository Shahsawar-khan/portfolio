# Shahsawar Khan — Personal Portfolio Website

A modern, fully responsive personal portfolio website built from scratch using **pure HTML5 and CSS3** — no frameworks, no templates, no JavaScript. Designed to showcase my profile, technical skills, education, projects, and contact information through a clean and professional web interface.

## 📌 Project Overview

This portfolio was built as part of the **Devixo Solutions Web Development Internship — Task 01**. The goal was to design and develop a professional personal portfolio using only semantic HTML5 and modern CSS3, with a strong focus on responsive design, clean code organization, and a professional color theme.

---

## ✨ Features

- **Fully responsive** — works on desktop, laptop, tablet and mobile
- **Semantic HTML5** — proper use of `header`, `nav`, `main`, `section`, `article`, `footer`
- **CSS-only mobile navigation** — hamburger menu built without JavaScript
- **Smooth scrolling** navigation between sections
- **Hover animations** on buttons, navigation links, skill cards, project cards and social icons
- **Dark professional theme** with warm orange accent color
- **Progress bars** for technical skills
- **Timeline layout** for education and experience
- **Project cards** with images, tech tags, and GitHub links
- **Working contact form UI** (front-end only, no backend)
- **Custom scrollbar** and selection styling

---

## 🛠️ Technologies Used

| Technology | Purpose |
|---|---|
| **HTML5** | Semantic structure and content |
| **CSS3** | Styling, layout, animations, responsive design |
| **Google Fonts (Poppins)** | Typography |
| **CSS Flexbox** | Navigation and component layouts |
| **CSS Grid** | Section and card layouts |
| **CSS Media Queries** | Responsive design (4 breakpoints) |

**No frameworks used.** No Bootstrap, no Tailwind, no JavaScript, no templates.

## 📑 Website Sections

1. **Home / Hero** — Name, tagline, introduction, profile image, call-to-action buttons, social links
2. **About** — Personal introduction, academic background, career interests, personal info list
3. **Skills** — 12 skill cards with progress indicators (HTML5, CSS3, JavaScript, Bootstrap, jQuery, PHP, Laravel, MySQL, WordPress, Git/GitHub, REST API, React)
4. **Education & Experience** — Timeline with degree, university, study period, and professional experience
5. **Projects** — 3 featured Laravel projects with images, descriptions, tech tags and GitHub links
6. **Contact** — Email, phone, location, social links + contact form (Name, Email, Subject, Message, Submit)
7. **Footer** — Copyright, brand info, quick links, services, contact details
