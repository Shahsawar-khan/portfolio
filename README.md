# Shahsawar Khan — Personal Portfolio Website

A modern, fully responsive personal portfolio website built from scratch using **HTML5, CSS3, and JavaScript**. Designed to showcase my profile, technical skills, education, experience, projects, and contact information through a clean, professional, and interactive web interface.

---

## 🚀 Live Demo

🔗 **Live Website:** https://shahsawar-khan.github.io/portfolio/

---

## 📌 Project Overview

This portfolio was built as part of my **Web Development Internship at Devixo Solutions — Task 01**. The goal was to design and develop a professional personal portfolio website with a strong focus on **responsive design**, **clean code organization**, **modern UI/UX**, and **interactive features** like dark/light mode.

---

## ✨ Features

- 🌙 **Dark / Light Mode Toggle** — Smooth theme switching with saved preference (localStorage)
- 📱 **Fully Responsive** — Works perfectly on desktop, laptop, tablet, and mobile
- 🎨 **Modern UI** — Clean layout with warm orange accent color
- 📝 **Semantic HTML5** — Proper use of `header`, `nav`, `main`, `section`, `article`, `footer`
- 🍔 **Mobile Navigation** — Hamburger menu with smooth animation
- ⚡ **Smooth Scrolling** — Navigation links scroll smoothly between sections
- 🎬 **Scroll Reveal Animations** — Elements fade in as you scroll
- 📊 **Animated Progress Bars** — Skill bars animate on scroll
- 🎯 **Active Nav Highlighting** — Current section is highlighted in the navbar
- ⬆️ **Scroll-to-Top Button** — Appears after scrolling down
- 💼 **12+ Projects Showcase** — All my full-stack projects with GitHub links
- 🎓 **Timeline Layout** — For education and professional experience
- 🏆 **Certifications Section** — All my certifications displayed
- 📧 **Working Contact Form** — Powered by Formspree
- 🔗 **Social Links** — GitHub, LinkedIn, Email
- 📄 **Download CV Button** — Direct download from the hero section
- 🎨 **Custom Scrollbar** — Styled for both themes

---

## 🛠️ Technologies Used

| Technology | Purpose |
|---|---|
| **HTML5** | Semantic structure and content |
| **CSS3** | Styling, layout, animations, responsive design |
| **JavaScript (ES6)** | Theme toggle, scroll reveal, animations, form validation |
| **Google Fonts (Poppins)** | Modern typography |
| **Font Awesome** | Icons |
| **CSS Flexbox** | Navigation and component layouts |
| **CSS Grid** | Section and card layouts |
| **CSS Media Queries** | Responsive design (4 breakpoints) |
| **LocalStorage API** | Save user's theme preference |
| **Intersection Observer API** | Scroll reveal animations |
| **Formspree** | Contact form backend |

**No frameworks used.** No Bootstrap, no Tailwind, no templates — pure vanilla code.
